# ShopEase – E-Commerce Website

## About the Project
ShopEase is a web-based e-commerce application developed using Python and Django. It allows users to browse products, manage their shopping cart, place orders, and view their order history.

## Features
- User registration, login, and logout
- Product listing, search, categories, and product details
- Shopping cart and Buy Now functionality
- Checkout and order confirmation
- My Orders and order details
- User profile management
- Wishlist and product reviews
- Stock management and order administration
- Sales dashboard and reporting

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite
- JavaScript (if used in the project)

## Installation and Setup

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Create and activate a Python virtual environment.
4. Install the required packages:

   `pip install -r requirements.txt`

5. Apply database migrations:

   `python manage.py migrate`

6. Start the development server:

   `python manage.py runserver`

7. Open `http://127.0.0.1:8000/` in your browser.
